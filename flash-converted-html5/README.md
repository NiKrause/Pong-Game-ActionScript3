# HTML5 Conversion

This folder contains the first HTML5 / JavaScript conversion of the original Flash Pong project.

Run it by opening:

```text
index.html
```

Controls:

- `Up Arrow`: move the player paddle up
- `Down Arrow`: move the player paddle down

Files:

- `index.html`: game shell and scoreboard
- `styles.css`: presentation and layout
- `game.js`: gameplay, rendering, and keyboard input
